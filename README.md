# 3-Input OR Gate using Diodes

## Project Overview

This project demonstrates the design and implementation of a **3-Input OR Logic Gate using Diodes**, developed as part of Basic Electronics coursework.

The circuit simulates OR logic behavior using discrete electronic components, reinforcing practical understanding of diode logic and digital electronics fundamentals.

---

# Objective

To design and test a diode-based 3-input OR gate and verify its logical operation for all input combinations.

---

# Working Principle

The circuit produces HIGH output when:

- Input A is HIGH
- Input B is HIGH
- Input C is HIGH
- Any combination of inputs is HIGH

The output remains LOW only when all inputs are LOW.

---

# Components Used

- Breadboard
- 3 × 1N4001 Diodes
- 3 × Slide Switches
- 3 × 1kΩ Resistors
- 1 × 220Ω Resistor
- 1 × LED Indicator
- Jumper Wires
- 9V Battery

---

# Circuit Operation

Each input switch is connected to the anode of a diode.

All cathodes are connected together and routed through a resistor to the LED output.

The LED turns ON whenever any input provides HIGH voltage.

---

# Truth Table

| Input A | Input B | Input C | Output |
|---------|---------|---------|--------|
| 0 | 0 | 0 | OFF |
| 1 | 0 | 0 | ON |
| 0 | 1 | 0 | ON |
| 0 | 0 | 1 | ON |
| 1 | 1 | 1 | ON |
